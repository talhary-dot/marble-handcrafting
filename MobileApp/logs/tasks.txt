4. MULTI-TIER IMAGE ENGINE & NETWORKING
   - Created ApiClient (`com.sangtarash.app.net.ApiClient`):
     * Asynchronous HTTP engine using `HttpURLConnection` and thread pool executor.
     * Dynamic URL resolution handling both local relative paths (`/images/products/...`) and external Cloudinary CDN URLs.
     * Consumes `GET /api/products` (with optional `?category=...`) and `GET /api/products/[id]`.
   - Created ImageLoader (`com.sangtarash.app.net.ImageLoader`):
     * Multi-tier in-memory `LruCache<String, Bitmap>` (allocating 1/8th of runtime memory).
     * Sub-sampled bitmap downsampling (`calculateInSampleSize`) avoiding `OutOfMemoryError` on high-resolution stone photography.
     * Asynchronous background loading with view-recycling tag verification for smooth 60 FPS scrolling.
